# 🎧 Spotify Dashboard | Power BI

An interactive **Spotify Dashboard built with Microsoft Power BI** to analyze music trends, artists, songs, rankings, popularity, and other key insights from Spotify data.

## 📊 Dashboard Highlights

- 🎤 Artist & Song Analysis
- 🔥 Popularity Analysis
- 🏆 Top Rankings & #1 Hits
- 💿 Album vs. Single Analysis
- 🔞 Explicit vs. Non-Explicit Tracks
- ⏱️ Track Duration Analysis
- 📅 Year & Month Trends
- 📈 Interactive KPIs and Visualizations
- 🎛️ Interactive Slicers and Filters

## 🛠️ Tools & Skills

- Microsoft Power BI
- DAX
- Data Modeling
- Data Cleaning
- Data Visualization
- Interactive Dashboard Design

## 🎯 Project Objective

The goal of this project was to transform raw Spotify data into a **clean, interactive, and easy-to-understand dashboard** that allows users to explore music trends and discover meaningful insights through visual analysis.

## 💡 Key Learning

This project helped strengthen my practical skills in **Power BI, DAX, data modeling, visualization, and dashboard development**, while focusing on presenting data in a clear and engaging way.
